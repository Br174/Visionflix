PURPOSE
Persistent project-side structural hook for MotorLab. When the execution surface identifies this repository/project, MotorLab is implicitly enabled and must load the current canonical CORE from Br174/Chatgpt before write-capable or lifecycle-changing work.

MANDATORY RULES
1. Do not require Bruno to paste an activation string in each new Visionflix/Verlezza Vision chat.
2. At the first available user-facing response of every recognized Visionflix/Verlezza Vision chat/session, visibly state that MotorLab is active and operating alongside the project's native engine.
3. If the visible MotorLab startup message has not appeared, Bruno must not be expected to assume that MotorLab is active.
4. After startup, apply the current MotorLab progress percentage, watchdog lightning/recovery and verified fireworks-success contracts whenever applicable.
5. Br174/Chatgpt remains authoritative; do not freeze a CORE copy here.
6. MotorLab operates alongside Visionflix native/domain engines and must not replace, disable, absorb or rewrite them merely because MotorLab is active.
7. Before write-capable/lifecycle work, reconcile current CORE/governance/routing/registry and relevant durable job/checkpoint/lock state.
8. This hook is orchestration metadata only and must not alter application logic, Mobile/TV UI, signing, package identity, Downloader behavior or playback functionality by itself.
9. If control state is unavailable, preserve project state and report the blocker rather than guessing.
10. Later canonical MotorLab governance revisions supersede frozen assumptions in this hook.
