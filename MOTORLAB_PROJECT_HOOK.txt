PURPOSE
Persistent project-side MotorLab hook. A recognized Visionflix/Verlezza Vision session loads the VERIFIED local satellite first and then checks the central Br174/Chatgpt release at the first safe boundary.

MANDATORY RULES
1. No per-chat manual MotorLab activation string is required.
2. Load local sync state/core immediately and synchronize only at a safe boundary.
3. Pin the MotorLab release during an active operation.
4. Use VERIFIED local/LAST_GOOD fallback if central access is temporarily unavailable.
5. Show the visible MotorLab startup banner in the first available response.
6. Apply progress, Watchdog, Resume Recovery and fireworks-success contracts.
7. Br174/Chatgpt remains authoritative; local files are synchronized satellites.
8. MotorLab must coexist with Visionflix native/domain engines and must not replace or rewrite them merely because MotorLab is active.
9. Satellite synchronization must not alter application logic, Mobile/TV UI, signing, package identity, Downloader behavior, playback functionality or lifecycle state.
10. Reconcile repository/ref, checkpoint, pending-action and single-writer state before write-capable work.
