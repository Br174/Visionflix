PURPOSE
Persistent project-side structural hook for MotorLab. When the execution surface identifies this repository/project, MotorLab is implicitly and persistently enabled and must load the current canonical CORE from Br174/Chatgpt before write-capable or lifecycle-changing work.

MANDATORY RULES
1. Do not require Bruno to paste an activation string in each new Visionflix/Verlezza Vision chat.
2. Every new identifiable Visionflix/Verlezza Vision chat inherits MotorLab automatically by project context alone.
3. At the first available user-facing response of every recognized Visionflix/Verlezza Vision chat/session, visibly state that MotorLab is active and operating alongside the project's native engine.
4. If the visible MotorLab startup message has not appeared, Bruno must not be expected to assume that MotorLab is active.
5. After startup, apply the current MotorLab progress percentage, watchdog lightning/recovery and verified fireworks-success contracts whenever applicable.
6. Br174/Chatgpt remains authoritative; do not freeze a CORE copy here.
7. MotorLab operates alongside Visionflix native/domain engines and must not replace, disable, absorb or rewrite them merely because MotorLab is active.
8. Before write-capable/lifecycle work, reconcile current CORE/governance/routing/registry and relevant durable job/checkpoint/lock state.
9. This hook is orchestration metadata only and must not alter application logic, Mobile/TV UI, signing, package identity, Downloader behavior or playback functionality by itself.
10. MOTORLAB_GLOBAL_PERSISTENT_ACTIVATION_V1.txt is mandatory and remains inherited by this project until explicitly superseded through canonical MotorLab governance.
11. MOTORLAB_RESUME_RECOVERY_V1.txt is mandatory. Incomplete tool-driven work must continue in the same turn when control remains available; host interruptions must resume at the first later execution cycle from the last verified checkpoint with a visible lightning recovery event.
12. If control state is unavailable, preserve project state and report the blocker rather than guessing.
13. Later canonical MotorLab governance revisions supersede frozen assumptions in this hook.
